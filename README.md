# Tradelog

Простий журнал трейдера в браузері — без реєстрації та сервера.

- Огляд: PnL, win rate, profit factor, очікування, R, просадка, серії
- Крива капіталу та календар PnL з тепловою картою
- Інсайти: які сетапи, емоції, дні тижня й тікери приносять/зливають гроші
- Розбір кожної угоди: графік зі стопом і тейком на сітці (реальні свічки Binance для крипто-пар, схема для решти), карта ціни (стоп / вхід / вихід / ціль), усі цифри, місце в журналі, порівняння із середніми, статистика сетапу
- Калькулятор розміру позиції та R:R
- Імпорт закритих позицій з OKX через API-ключ «тільки читання» (запити підписуються прямо в браузері)
- Експорт/імпорт JSON, демо-дані

Дані зберігаються лише у `localStorage` твого браузера.
