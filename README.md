# 📈 TradeLog

Простий журнал трейдера в браузері — без реєстрації та сервера.

- Дашборд: PnL, win rate, profit factor, очікування, R, просадка, серії
- Крива капіталу та календар PnL з тепловою картою
- Інсайти: які сетапи, емоції, дні тижня й тікери приносять/зливають гроші
- Калькулятор розміру позиції та R:R
- Експорт/імпорт JSON, демо-дані

Дані зберігаються лише у `localStorage` твого браузера.
